# MyFlix

MyFlix is a platform for watching movies and TV shows that I will be creating in **C#**.
The project is inspired by modern video streaming services such as Netflix.

---

## Project Goal

- Develop a web application for watching movies and TV shows.
- Implement user authorization and registration functionality.
- Create a page with movie details and the ability to add to favorites.

---

## Technologies

- Backend: C# (.NET 7/ASP.NET Core)
- Frontend: HTML, CSS, JavaScript
- Database: SQLite / PostgreSQL
- Movie API: OMDb API or similar
